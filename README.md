# Halo

Spatial glass job card on a live **D2Q9 Lattice Boltzmann** field.

- Frosted glass panel, save pill, chips, gradient CTA
- Night / dawn type (white on dark frost, ink on milky frost)
- Shader looks: Veil, Magenta, Ember, Ion, Dawn
- Drag the scene to inject momentum
- Lab: Force, Fluidity, Stars

```bash
npm install
npm run dev
```

## Reuse the glass in another app

Copy [`kit/`](kit/README.md) — `glass.css` + `GlassCard.tsx`. Leave FluidField / nebula behind.
